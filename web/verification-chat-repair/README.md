# 2026-10-11 连续对话与自动语音修复

## 复现与修改
- 已在 Chromium 复现：回复尚未返回时第二次发送会清空草稿，但 useEmotionChat 直接 return，第二条请求没有发出。
- 发送期间禁用发送（仍可编辑下一条草稿），同步 ref 防重复，成功后只清除原草稿，失败保留文字并显示持久提示；每轮都显示等待状态。
- AI 文字回复默认自动调用 TTS 并播放同一段文字。发送/录音手势内激活播放器；区分合成中、播放中、播放被拦截、合成失败。可重播已生成音频或重试合成。
- 中断清除音源、取消请求并递增 generation，迟到音频丢弃；释放 Blob URL。
- 缓存会话先 resume，404/410 后重建；并发初始化合并；JSON 请求与 TTS 有 45 秒上限。
- 保留公共 ActionButton 替换机制，新增 chat.replay 配置。
